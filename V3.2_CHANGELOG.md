# Elena Yoga V3.2

## Blue guide change

V3.2 changes only the target blue-skeleton geometry. The classifier, MediaPipe pose detection, angle scoring, feedback rules, API routes, and frontend layout remain unchanged.

- **Reference pose controls direction / pose geometry.** The target direction of each major limb segment comes from the normalized reference CSV landmarks.
- **Current user controls segment length.** Shoulder width, hip width, torso length, upper/lower arms, upper/lower legs, hand branches, and foot branches use the current user's MediaPipe landmark distances in **image pixel space**.
- **Stable torso anchor.** The target skeleton is centered on the user's mid-hip, then shoulder and hip widths are rebuilt using the user's proportions and reference directions.
- **No `reference_deg` ray reconstruction for the blue skeleton.** This keeps the V3.1 fix that avoids V2's angle-only guide reconstruction.
- V3.1 whole-body alignment remains only as a fallback for face/degenerate segments.

## Easier startup

Double-click `START_YOGA_V3.2.bat` from the project root. On the first run it creates `backend/.venv`, installs backend + frontend requirements, starts both services, and opens `http://localhost:8080`. Later runs reuse the same environment.
