Elena Yoga V3.1
================

Purpose of this revision:
- Keep the V3 blue reference-landmark visualization changes.
- Fix the incomplete backend dependency list that caused missing uvicorn / fastapi / joblib errors.
- Add a dependency verification step before backend startup.

Recommended Windows setup: Python 3.11 (64-bit).

Easiest backend startup:
1. Extract this ZIP to a NEW folder. Do not overwrite V2 or V3.
2. Right-click START_V3.1_BACKEND.ps1 and run with PowerShell.
   Or open PowerShell in this folder and run:
   powershell -ExecutionPolicy Bypass -File .\START_V3.1_BACKEND.ps1
3. Wait for: Application startup complete.
4. Keep that terminal open.

Static web frontend (open a SECOND terminal in this project folder):
   py -3.11 -m http.server 8080 --bind 127.0.0.1 --directory frontend/web
Then open http://127.0.0.1:8080

V2 and V3 can remain on the computer as separate folders.
